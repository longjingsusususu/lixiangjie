## 二、工程架构（2-会议需求MVP）

四层单体，全部服务端强制（客户端不可绕过）：

```
┌─ 入口层  GET / （登录页 + 五角色单页工作台）
├─ 接口层  FastAPI 路由（JWT HttpOnly，19 个 API）
│          其中 GET /api/ask 为 Agent 问答入口（只读）
├─ 编排层  Agent Harness（decide→invoke→observe，MAX_ROUNDS=3，规则驱动零 LLM）
│          ├─ f24015105_agent_harness.py   编排器 + 工具注册表（TOOLBOX 槽位）
│          └─ f24015105_knowledge.py       知识库检索（bigram 加权打分 + 覆盖门）
├─ 服务层  五态状态机 / 定版规则(f24) / 交接卡口(f20) / 异常队列(f44) / 编号映射幂等(f30)
└─ 数据层  SQLite WAL，11 张表（requirement_items 双时间戳+五态分列第一天进 schema）
```

**文件清单**：
- `f24015105_meeting_server.py` —— 主服务（852 行，含前端单页）
- `f24015105_agent_harness.py` —— Agent 编排框架（人工审核点④问答侧兜底在此实现）
- `f24015105_knowledge.py` + `f24015105_kb_data.json` —— 知识库（10 篇规则文章，全部锚定 f 编号证据）
- `f24015105_meeting_seed.py` —— 50 项虚构演练样本灌库（f12 口径）
- `f24015105_meeting_tests.py` —— 五场景 81 项断言（当前 81/81 全绿）

**运行**：`python f24015105_meeting_seed.py --force && python f24015105_meeting_server.py`（默认 8800 端口）。

## 三、Agent 框架（Harness）

沿用问答助手已验证的编排三段式，替换 LLM 规划器为规则路由：

| 段 | 实现 | 二期升级槽位 |
|---|---|---|
| decide | 意图路由表（统计类词→看板工具；规则类词→知识库工具） | 换成 LLM 规划器（供应商可替换） |
| invoke | TOOLBOX 工具注册表：`stats`（直连 DB 取 M6/M7）、`kb_search`（知识库检索） | 新增工具只改注册表 |
| observe | 成功→组答案带引用；覆盖门未过/异常→**转人工**，绝不硬答 | 观察层零改动 |

**知识库**：结构化规则库（KB-01~10：五态、三要素、双时间戳、定版、异常、红线、权限、指标、映射、安全），检索为中文 bigram 加权打分（BM25 简化版），覆盖门阈值 0.25（校准：有效业务问题实测 ≥0.29，无关问题 0.0）。每条回答带引用（条文编号 + f 证据锚）。二期接 RAG 时对外接口不变。

## 四、人工确认/审核点（4 处 > 要求的 3 处）

| # | 卡口 | API | 规则 | 证据 |
|---|---|---|---|---|
| ① | **需求确认签字** | `POST /api/items/{id}/confirm` | 未确认→已确认必须由业务负责人/协调员人工签字；登记人不能确认自己登记的项（编辑权/确认权分离） | f22 |
| ② | **手动定版** | `POST /api/versions/{vid}/finalize` | 系统生成版本号不可编辑；"有效期+确认状态"双条件判有效（f24）；过期来源不得覆盖（f34） | f24/f34 |
| ③ | **交接三要素卡口 + 接收确认** | `POST /api/handovers` → `/ack` | 接收人/版本号/未结项数缺一拦截不放行（提醒式无效，拦截式有效）；交接成立后接收方仍需确认 | f20 |
| ④ | **异常队列人工复核** | `POST /api/exceptions/{eid}/claim`→`/close` | 字段缺失/冲突/脏数据/版本无法确认四类入队；不得默认通过（无"自动通过"状态）；脏数据保留原行 | f44/f33 |

Agent 侧兜底（同属审核机制）：知识库未覆盖的问题一律转人工，不硬答；`/api/ask` 为只读接口，不产生任何确认/定版/交接动作。

## 五、测试与验证记录

- 五场景量化测试：**81/81 全绿**（正常 23 / 边界 16 / 对抗 13 / 权限 19 / 故障 10），执行器可重复运行；
- Agent/知识库验证（2026-11-06 实测）：知识库命中 6/6 带引用（KB-02/04/03/08 等）；无关问题 3/3 转人工；`/api/ask` 端到端 3/3 符合预期；回归 81 项无破坏。
