# f24015105 · 员工问答入口 MVP

对应需求《f24015105_用户端聊天界面_接口设计与前端规格.md》的最小可运行版本。
正式版（JWT 鉴权、五态状态机、审计留痕、限流）在 `app/portal.py` + `app/static/index.html`，本 MVP 只保留提示词里点名的最小闭环。

## 文件

| 文件 | 说明 |
|---|---|
| `f24015105_mvp_server.py` | 单文件后端：POST /api/chat（SSE）、GET /api/sessions、GET /api/sessions/{sid}/messages |
| `f24015105_index.html` | 单页前端：打字机效果、「正在检索需求项…」状态条、命中需求项卡片、底部引用来源 |
| `f24015105_mvp_smoke.py` | 冒烟测试 16 项（错误码契约 / SSE 事件序 / SQLite 落库 / 6 轮上下文追问） |

## 运行

```bash
pip install -r ../requirements.txt   # fastapi / uvicorn / jieba / rank-bm25 / numpy
python f24015105_mvp_server.py       # 默认 http://127.0.0.1:8020，浏览器打开即用
```

数据库自动落在 `mvp/f24015105_mvp.db`（已在 .gitignore），首启加载 `data/demo_会议需求样例.md` 的 18 条需求项。

## 契约要点

- **错误先于建流**：所有校验在建 SSE 之前完成，失败返回普通 JSON `{"code": 40001, "message": "问题不能为空"}`（40001 空问题 / 40002 超 200 字 / 40401 会话不存在 / 50301 索引未就绪 / 50001 兜底）。
- **SSE 事件序固定**：`status`（正在检索需求项…）→ `item`×N（命中的需求项卡片）→ `chunk`×M（8 字一段）→ `done`（含 citations）；任意阶段可 `error`。
- **会话与消息入 SQLite**：`sessions` / `messages` 两表最小结构；用户消息先落库再检索，异常也留下提问痕迹。
- **最近 6 轮上下文**：短问题（≤8 字）自动拼接历史里出现的类别词，"那餐饮呢？"这类省略式追问可命中。
- **引用来源**：`来源工具｜单据号｜行位置` + 40 字片段，随 `done` 与历史消息返回，回看可复现依据。
- **一期零 LLM**：汇总为确定性规则文案（统计 + 点名），不做任何推断。
