## 一、目标与范围（Q1/Q10）

**目标**：把"登记分散、版本靠猜、交接只发已处理"的现状（E-01，f23/f24），改造为"每项有责任人、有确认状态、有版本、有来源"的需求汇总系统，验收口径为 **50 个服务项全部具备责任人与确认状态且变更可追溯**（f42）。

| 一期做 | 说明 |
|---|---|
| ① 需求登记与汇总 | 单批次 50 项，双轨兜底（群消息先、系统补录，延续 f13 现实） |
| ② 版本定版 + 交接卡口 | 系统生成版本号，维护人手动定版；交接强制三要素（f20） |
| ③ 异常人工队列 | 缺项/冲突/脏数据入队，不得默认通过（f44） |
| ⑦ 统计看板 | M6/M7/M8 自动埋点，M1/M5 采样 |
| ④ 只读集成（待定→降级路径） | 三套工具只读聚合（f30/f32）；**接口开不了则降级为每周批量 CSV 导入** |

**二期**：⑤ LLM 需求抽取向导 + 制度问答（复用报销助手 RAG 架构）｜**不做**：⑥ 供应商侧入口；自动邀请真实嘉宾、发布会议安排、确认敏感个人需求、任何写回与外部接口（f05/f52/f32，永久不做清单）。

## 二、用户与角色（Q6，按访谈确认点设计）

| 角色 | 对应人 | 权限 |
|---|---|---|
| 一线专员 | 林亦舟 | 登记/补录需求项，提交确认申请 |
| 协调员 | 唐映秋 | 定版、发起交接、维护未结项 |
| 业务负责人 | 顾明岚 | **确认签字**（REQ-1）、试点范围调整 |
| 质量验收 | 傅景 | **质量签字**（REQ-2）、异常闭环判定（REQ-3）、暂停权 |
| 管理员 | 秦芮 | 字段配置、数据导入、脱敏规则 |

设计原则：**编辑权限与确认权限分离**，模型无任何审批权限（f22 红线）。

## 三、关键架构决策（十问基线，2026-11-06 已确认）

| 题 | 决策 | 选择 | 理由 |
|---|---|---|---|
| Q1 | 系统形态 | B 自研轻量 Web（SSR 单体） | 强制卡口/权限分离/留痕四项表格工具给不了（f02/f42） |
| Q2 | 数据入口 | A 接口为主 + B CSV 兜底 + C 双轨保留 | 三路留口子；接口开放性待秦芮确认（R4）；双轨补录记录双时间戳（f13/f34） |
| Q3 | 需求项结构 | B 完整版 | 无"来源记录+变更历史"则 M7 可追溯率无法计算；附件挂单留二期 |
| Q4 | 版本管理 | B 系统生成版本号 + 手动定版 | 消灭文件名猜版本（f24）；维护人待顾明岚/傅景确认（R2） |
| Q5 | 交接卡口 | B 拦截式强制三要素（f20） | 行业结论"提醒会被忽略，拦截不会"；时点口径待顾明岚签字（R1） |
| Q6 | 异常处理 | B 内置人工队列 | 值守人/响应时限待傅景点名（R3）；不得默认通过（f44） |
| Q7 | 智能化 | A 一期纯结构化埋槽位，LLM 二期 | 抽取可自动化、确认必须人工（f22）；f01 红线 + 32 人时预算装不下 LLM |
| Q8 | 部署 | C 云部署+字段级脱敏 | 嘉宾敏感需求（f52）不入明文库；脱敏粒度待秦芮/傅景确认（R6） |
| Q9 | 指标测量 | B 混合 | M6/M7/M8 埋点自动，M1/M5 线下采样（f03 预算内现实可行） |
| Q10 | 交付形态 | B 持续运营 + 轻量配置后台（≤5 页面） | 编号映射等规则必变，一次交付写死必返工；不做通用低代码平台 |

## 四、非功能需求

- **双时间戳**：每条记录区分业务发生时间与系统接收时间（f13/f34），表结构强制字段；
- **留痕四项**：谁查过、哪个版本、什么建议、谁确认（f44 要求）；
- **只读边界**：不写回、不开放外部接口；读取失败保留快照并标记时间（f35）；
- **暂停条件**：无法确认版本或关键字段进人工队列，必要时暂停，不得默认通过；
- **性能**：单批次 50 项、并发 ≤10 人，普通云主机足够，无需水平扩展。

|---|---|---|

## 六、风险与开放问题（访谈遗留待定项）

1. **三套工具只读接口能否开放**（Q2/R4）——开不了则一期走 CSV 导入，集成模块顺延；
2. **版本规则维护人与复核周期**（Q4/R2）——待顾明岚/傅景确认，阻塞定版功能上线；
3. **异常队列值守人与响应时限、暂停恢复条件**（Q6/R3）——待傅景点名、顾明岚批准，阻塞队列有效性；
4. **交接责任转移时点**（Q5/R1）——两个口径未定，卡口字段无法定稿，待顾明岚签字；
5. **M1 处理时长 / M5 复核成本基线全缺**（R7）——试点首周实测，不预填目标；
6. **敏感字段脱敏粒度与留存期限**（Q8/R6）——待秦芮、傅景确认。

> 以上 6 项全部来自业务挖掘附录 A 的"执行层口径未核实"清单，属于**上线前置条件**而非可延后优化项。
