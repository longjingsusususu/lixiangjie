## 1. 当前状态

本仓库当前为**文档库 + 构建脚本**形态：

- `docs/01-business/` — 业务挖掘：典型事件资料 E-01（六轮访谈取证，md/docx/html）、访谈原文；
- `docs/02-requirements/` — 需求：需求报告 v1.0（md/docx/html）、一页纸需求清单、需求分析与技术选型（十问架构分叉，基线已确认 v1.1）；
- `docs/03-architecture/` — 架构与交付：技术架构选型、系统需求分析方案（v1.0，9 章 3 附录）、**三档报价与投入产出测算 v2.0**（低 ¥30,000 / 中 ¥55,000 / 高 ¥100,000）、**上线交付运行手册 v1.0**（11 章 2 附录）、三案设计方案、报价单 v1.0、行业分析 v2.1、流程图（现状/改造前融入 E-01/现状与 AI 对照）；
- `docs/03-architecture/会议活动需求/` — 按 1~6 编号归档的需求全材料；
- `scripts/` — `build_report_docx.py` / `build_report_html.py`（md→docx/html 可复用构建器，支持封面/自动目录/表格底纹/代码块）、`draw_e01_flow.py`（流程图绘制）；
- `data/` — 18 条会议需求合成样例（演示数据，不含真实客户信息）。

## 3. 构建 docx / html

```bash
python scripts/build_report_docx.py <input.md> <output.docx> <主标题> <副标题>
python scripts/build_report_html.py <input.md> <output.html>
```

md 需含 `| 资料编号 | xxx |` / `| 版本 | vX.Y |` 文档控制表，封面与目录自动生成。
