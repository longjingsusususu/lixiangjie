# 流程图索引

四张图都在本目录。`改造前` 与 `改造后` 是同一套骨架的两版对照；`融入 E-01` 是改造前版叠加典型事件卡取证结果的版本。

| 文件 | 是什么 | 用在哪 |
|---|---|---|
| `会议活动服务需求汇总_现状流程图.png` | **改造前**：13 个节点（9 处理 + 4 判断）、3 个断点、底部量化口径 | 讲现状怎么走、断在哪 |
| `会议活动服务需求汇总_改造前流程图_融入E-01.png` | **改造前 + 典型事件 E-01**：五个交接节点挂取证徽标，25 字段全标注待采集，节点右侧标出对应的改造后阶段（S1–S9） | 讲"问题不是猜的，是访谈取证到的" |
| `会议活动服务需求汇总_AI数智化后流程图.png` | **改造后**：S1–S9 九个环节，逐环节标 30.8 → 15.8 人时（虚构样本）与降幅 | 讲改成什么样、省在哪 |
| `会议活动服务汇总_现状与AI对照流程图.png` | 改造前与改造后的合并对照图 | 一页讲清前后差异 |
| `会议活动服务需求汇总_流程图.html`、`..._现状流程图_长图版.html` | 网页版（可缩放、可打印） | 投屏或需要放大看细节时 |

绘图脚本：`scripts/draw_e01_flow.py`（生成 E-01 融入版，改文案后重跑即可）。

## 口径提醒

- 图中 `待采集 / 无记录` 是访谈当时的真实状态，不是资料缺陷，不要替换成估算值；
- 50 项为验收口径值而非实测；30.8 / 15.8 人时为虚构样本，需标注后才可引用；
- E-01 版不含任何业务数字，只标证据状态——这是刻意设计，避免把推断当基线。
