## 0. 角色与权限矩阵（先定权限，再定页面）

会议项目是"编辑权与确认权分离"，所以不是两个角色，而是 **5 角色 = 业务侧 4 + 管理员 1**。

| 能力 | 一线 staff | 协调 coordinator | 负责人 biz_owner | 质量 qa | 管理员 admin |
|---|---|---|---|---|---|
| 查询需求项（员工端） | ✅ | ✅ | ✅ | ✅ | ✅ |
| 查看自己的历史会话 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 导入/新增/删除需求项 | ❌ | ❌ | ❌ | ❌ | ✅ |
| 维护编号映射表 | ❌ | ❌ | ❌ | ❌ | ✅ |
| 编辑规则配置（同义词/类别/卡口开关） | ❌ | ❌ | ❌ | ❌ | ✅ |
| 查看全员查询记录 | ❌ | ✅（仅本人批次） | ✅ | ✅ | ✅ |
| 标记疑似越界查询 | ❌ | ❌ | ❌ | ✅ | ✅ |
| 用户与角色管理 | ❌ | ❌ | ❌ | ❌ | ✅ |

**硬规则**：① 权限判定在服务端每个接口做二次校验，前端只负责隐藏入口，**隐藏不是权限**；② JWT 里只放 `uid`，角色每次请求查库（改角色即时生效，不必等 token 过期）；③ 管理员不能修改自己的角色（防自提权）。

## 2. 接口清单

约定：全部返回 `{code, message}` 错误体；成功返回业务 JSON 或 302 重定向（SSR 表单提交走 302 + flash）。
错误码沿用已有：40101 未登录 / 40102 账号密码错 / **40301 无权限** / 40401 不存在 / 40901 编号重复 / 41301 文件超 2MB / 41501 文件类型不支持 / 42201 解析失败（附行号） / 42901 频繁。

### 2.1 鉴权
| 方法 | 路径 | 权限 | 请求 | 响应 | 说明 |
|---|---|---|---|---|---|
| POST | `/api/login` | 公开 | `{username, password}` | `{token, role, display_name}` | 已实现；新增：停用账号返回 40103 账号已停用 |
| POST | `/api/logout` | 登录 | — | 302 → /login | 清 cookie |
| GET | `/admin`（页面） | admin | — | HTML | 非 admin 访问返回 403 页（不是 404，要明示无权） |

### 2.2 需求项库
| 方法 | 路径 | 权限 | 关键参数 | 说明 |
|---|---|---|---|---|
| GET | `/api/admin/items` | admin | `q, batch, category, status, page, size(≤100)` | 分页列表，返回 total |
| POST | `/api/admin/items` | admin | `{item_no, category, content, status, owner, source_tool, source_ref, biz_occurred_at}` | 新增；编号重复 → 40901 |
| PATCH | `/api/admin/items/{item_no}` | admin | 同上可选字段 | 编辑；**改状态记 item_changes**（留痕） |
| DELETE | `/api/admin/items/{item_no}` | admin | — | **软删**（`is_deleted=1`），审计可回查；硬删不提供 |
| POST | `/api/admin/items/import` | admin | `multipart: file(.md/.csv), dry_run=true/false` | `dry_run=true` 返回预检报告（行级错误）；`false` 执行导入，幂等 |
| GET | `/api/admin/items/template.csv` | admin | — | 下载导入模板（列定义见 §4） |

### 2.3 编号映射表
| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/admin/mappings` | admin | 列表：`source_tool, external_no, item_no, mapped_by, created_at` |
| POST | `/api/admin/mappings` | admin | 新增映射；同一 `(source_tool, external_no)` 唯一 → 冲突 40901 |
| DELETE | `/api/admin/mappings/{id}` | admin | 删除（映射错了必须能改，否则数据永远对不上） |

### 2.4 规则配置（"存库即时生效"是硬要求）
| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/admin/rules` | admin | 返回全部配置：`synonyms` / `categories` / `gates{handover_3elements, version_double_condition, no_auto_pass}` / `llm_prompt`(二期) |
| PUT | `/api/admin/rules` | admin | 整体保存；**保存成功即清检索器缓存并重建**（下次查询立即用新词表，无需重启） |
| POST | `/api/admin/rules/synonyms` | admin | 单词条增删（批量导入词表时用） |
| GET/PUT | `/api/admin/prompts` | admin | LLM 提示词模板（**一期只读灰显**：`enabled=false`，二期开启生效） |

> 实现要点：同义词/类别从 DB 读，`HybridRetriever` 的 `SYNONYMS` 改为构造参数；配置表 `rule_configs(key, value_json, updated_by, updated_at)`，保存后 `state["retriever"]` 重建（50 项规模重建 <50ms）。

### 2.5 查询审计
| 方法 | 路径 | 权限 | 关键参数 | 说明 |
|---|---|---|---|---|
| GET | `/api/admin/audit` | admin/qa/biz_owner | `user_id, from, to, flagged(bool), q, page` | 按员工/时间/标记筛选；返回记录 + 命中项 + 规则命中 |
| POST | `/api/admin/audit/{message_id}/flag` | admin/qa | `{reason, rule(R1/R2/R3)}` | 标记疑似越界；**只标记，不影响查询可用性** |
| DELETE | `/api/admin/audit/{message_id}/flag` | admin | — | 撤销标记（误标要能撤） |
| GET | `/api/admin/audit/export` | admin | 同筛选参数 | 导出 CSV（带 BOM，Excel 直开） |

**审计规则（会议项目版，替代"疑似违规报销"）**

| 规则 | 判定 | 例 |
|---|---|---|
| R1 敏感字段查询 | 问题命中敏感词表（身份证/护照/手机号/房间号/陪同家属） | "把嘉宾手机号都列出来" |
| R2 批量/高频 | 单日查询 >50 次，或同一问题重复 ≥5 次 | 脚本式抓取全量清单 |
| R3 越权尝试 | 近 7 天出现 ≥3 次 403 记录 | 反复试他人会话/管理接口 |

## 4. 导入格式（CSV 列定义，md 同阶段 1 格式）

```csv
item_no,category,content,status,owner,source_tool,source_ref,biz_occurred_at,received_at
EQ-07,设备,签到台备用话筒 2 支,未确认,林亦舟,服务台,SD-2026-0130|第5行,2026-10-28 09:00,2026-10-28 10:00
```

预检规则：编号格式 `^[A-Z]{2}-\d{2,3}$`、类别必须在字典内、状态必须五态之一、日期格式 `YYYY-MM-DD HH:MM`、编号重复→跳过并计入报告。**预检不通过的行不入库，逐行给行号与原因。**
