## 3. 用例驱动修掉的四个真缺陷（已落地并回归）

1. **陷阱题被弱匹配凑数**：检索器对任何问题都能排出前 3 名。已在 `search_items` 工具层加**关键词覆盖门**——去停用词后实质词命中率 <50% 的条目直接丢弃，宁可答"未覆盖"；
2. **"缺项清单/还有多少没确认"被当普通检索**：`check_completeness` 扩了全量模式（缺失/未确认分列，f31），planner 加路由；
3. **FAQ 被 handover 意图截走**："交接需要哪些要素"含"交接"两字会进写操作分支追问编号——FAQ 判定提前到所有意图分支之前；
4. **停用词污染覆盖门**："状态/分别/信息"等泛词会拖低真命中的覆盖率，补进停用表。

回归：六套冒烟 **196 项断言全过**（20+22+30+28+38+58）。
